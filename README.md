# Hollow Toll

A creepy 3D slot-machine roguelike in a single `index.html` (three.js, no build step).

You are chained in an undercroft before an old brass machine. Every night the Maw in the wall demands coins, and the spiked ceiling sinks a little lower. Pull the lever, match symbols in patterns, buy relics from the Peddler's hatch, and feed the Maw before you run out of cranks. Survive ten nights.

**Play:** open `index.html` in a browser (an internet connection is needed for three.js and fonts from CDN).

**Keys:** Space pull · C buy crank · E peddler · F feed · H rules · M sound
